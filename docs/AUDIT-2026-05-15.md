## Divergências críticas (2)

### 1. fingerprint-pipeline.md — HopSize errado

- **Doc:** `HopSize | 1024` (tabela linha 103) + diagrama linha 16 "STFT (4096 / 1024 hop, Hann)"
- **Código:** `HopSize = 2048` ([workers/pkg/audio/stft.go:12](workers/pkg/audio/stft.go#L12))
- **Impacto:** frames/s = 16000/2048 ≈ 7.8 (não ~15.6). Doc induz erro em qualquer cálculo derivado.
- **Ação:** corrigir tabela e diagrama (manter doc, só atualizar valor).

### 2. material-similarity-warning.md — Threshold errado

- **Doc:** "score ≥ 15%" (linha 8) + "hard-coded at 15%" (linha 17)
- **Código:** `WarnThreshold = 0.50` ([workers/internal/similarity/similarity.go:35](workers/internal/similarity/similarity.go#L35))
- **Justificativa do código (comentário linhas 29-34):** 15-25% é zona de "sting compartilhado intencional, não bloquear". 50%+ é subset/near-duplicate, aí sim bloqueia.
- **Impacto:** doc descreve comportamento mais permissivo do que o código aplica. Operador lê doc, espera modal aparecer em sting de 20%, e ele não aparece.
- **Ação:** corrigir doc para refletir 50% + nota explicando calibração 15/25/50.

## Divergências significativas (4)

### 3. backup-and-retention.md — Comando errado

- **Doc:** `pg_basebackup -F tar -z -X stream`
- **Código:** `pg_dump -Fc` em `infra/scripts/backup.sh:127`
- **Por quê:** pg_basebackup exige role de replication + pg_hba.conf que não existem no compose.
- **Ação:** corrigir trecho §1.1 e §1.5; doc cita arquivo `.tar.gz`, na verdade é `.dump`.

### 4. fingerprint-pipeline.md — CLI legado (nomenclatura)

- **Doc:** descreve `--commercial-short-id`, fluxo polimórfico via `material_id` em outro doc.
- **Código:** CLI em `workers/cmd/fingerprint/main.go` ainda usa `--commercial-short-id`.
- **Veredito:** é consistente, mas a doc material-fingerprint-pipeline.md descreve um fluxo NATS polimórfico que coexiste com o CLI legado. Documentar essa coexistência.

### 5. broadcaster-search.md — Pendência backend não fechada

- **Doc:** menciona acento-insensibilidade no backend como pendência.
- **Código:** migration `0023_unaccent.up.sql` aplicou `CREATE EXTENSION unaccent`, mas `workers/internal/catalog/stations.go:155-176` ainda usa `ILIKE` puro (sem `unaccent(...)`).
- **Ação:** doc está correto em apontar pendência. Manter, e abrir follow-up de "aplicar unaccent() no WHERE".

### 6. StreamDownProlongado.md (runbook) — Rota inexistente

- **Doc:** sugere `PATCH /v1/internal/stations/{id}` para atualizar `stream_url`.
- **Código:** router não expõe PATCH para stations.
- **Ação:** remover ou trocar pelo verbo HTTP real.
